# Порівняння ketch з іншими

Кожен інструмент нижче добрий у тому, для чого створений; тут показано, де серед них розташований ketch.
Звірено з документацією кожного проєкту у вересні 2026 року.

| | ketch | Homebrew | apt | mise |
| --- | --- | --- | --- | --- |
| Потрібна заздалегідь написана формула чи пакет | Ні — будь-який `owner/repo` з асетами релізів; маніфест потрібен, лише якщо виведення помилилося | Так — формула або cask, у core або в tap | Так — `.deb` у налаштованому репозиторії | Ні для бекендів `github:` / `aqua:`; короткі імена беруться з його реєстру |
| Платформи | macOS, Linux, Windows | macOS, Linux | Linux родини Debian | macOS, Linux, Windows |
| Перевірка за замовчуванням | SHA-256, якщо реліз його публікує (файл контрольних сум або дайджест асета GitHub); підпис видавця, якщо маніфест оголошує `trust` | SHA-256, закріплений у кожній формулі | Підписані метадані репозиторію та хеші кожного пакета | Контрольні суми, якщо записані (конфіг або `mise.lock`); атестації GitHub і SLSA provenance, якщо вони є в релізу |
| Версіоноване сховище з відкатом | Так — попередня версія зберігається; `ketch rollback` перелінковує її | Старі версії лишаються до `brew cleanup`; команди відкату немає | Ні — знизити версію можна, лише якщо стара ще доступна | Версії поруч одна з одною; перемикання через `mise use tool@version` |
| Чисте видалення | `ketch uninstall`; `ketch self uninstall` видаляє все дерево `~/.ketch` і його блок PATH | `brew uninstall` (`--zap` для залишків cask) | `apt purge` видаляє пакет і його файли конфігурації | `mise uninstall`; `mise implode` видаляє сам mise |
| Збирання з вихідного коду | Ніколи | Якщо немає відповідного bottle | Ніколи (бінарні пакети) | Деякі бекенди збирають |

Чим ketch відрізняється від решти: `.app`-бандли в `/Applications`, пояснення кожного
вибраного асета та сховище, яке можна відкотити без звернення до мережі.
