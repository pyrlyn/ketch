# Сравнение ketch с другими

Каждый инструмент ниже хорош в том, для чего создан; здесь показано, где среди них находится ketch.
Сверено с документацией каждого проекта в сентябре 2026 года.

| | ketch | Homebrew | apt | mise |
| --- | --- | --- | --- | --- |
| Нужна заранее написанная формула или пакет | Нет — любой `owner/repo` с ассетами релизов; манифест нужен, только если вывод ошибся | Да — формула или cask, в core или в tap | Да — `.deb` в настроенном репозитории | Нет для бэкендов `github:` / `aqua:`; короткие имена берутся из его реестра |
| Платформы | macOS, Linux, Windows | macOS, Linux | Linux семейства Debian | macOS, Linux, Windows |
| Проверка по умолчанию | SHA-256, если релиз его публикует (файл контрольных сумм или дайджест ассета GitHub); подпись издателя, если манифест объявляет `trust` | SHA-256, закреплённый в каждой формуле | Подписанные метаданные репозитория и хеши каждого пакета | Контрольные суммы, если записаны (конфиг или `mise.lock`); аттестации GitHub и SLSA provenance, если они есть у релиза |
| Версионированное хранилище с откатом | Да — предыдущая версия сохраняется; `ketch rollback` перелинковывает её | Старые версии остаются до `brew cleanup`; команды отката нет | Нет — понизить версию можно, только если старая ещё доступна | Версии рядом друг с другом; переключение через `mise use tool@version` |
| Чистое удаление | `ketch uninstall`; `ketch self uninstall` удаляет всё дерево `~/.ketch` и его блок PATH | `brew uninstall` (`--zap` для остатков cask) | `apt purge` удаляет пакет и его файлы конфигурации | `mise uninstall`; `mise implode` удаляет сам mise |
| Сборка из исходников | Никогда | Если нет подходящего bottle | Никогда (бинарные пакеты) | Некоторые бэкенды собирают |

Чем ketch отличается от остальных: `.app`-бандлы в `/Applications`, объяснение каждого
выбранного ассета и хранилище, которое можно откатить без обращения к сети.
